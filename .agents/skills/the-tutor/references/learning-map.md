# 学习地图：怎么建、怎么长

> 地图是**学习者持有**的交付物，不是引导者心里的表。没有它，结构只活在引导者脑子里——
> "概念都听过、但串不起来"的直接来源。细则见本文件；状态取值见 `state-model.md` §1。

## 1. 第一版 v0（阶段 0，只要够开工）

1. **AI 提议，他只做减法**：按终点能力提议候选节点（每个配一句"它能让你做什么"），让他勾掉不要的。
   **不要让他从零列清单**——他不知道这个领域长什么样，列不出来。
2. **每条边都要能说出理由**：任何一条前置边，必须写出一句「**B 用到了 A 的什么**」。
   写不出来的边删掉（或降级"可选加深"）。这一步把"目录"变成依赖图——不做就是一张书目录。
3. **每个节点带状态，默认 `推测`**（`state-model.md` §1）。
4. **分级展开**——大主题靠这个才装得下：

   | 级别 | 内容 | 稳定性 |
   |---|---|---|
   | 粗：模块骨架 | 4–8 个模块，各一句"大致包含什么" | 稳定，跨会话必带 |
   | 中：当前圈 | 4–8 个节点，带边与理由 | 会变，走完一圈重排 |
   | 细：当前节点 | 一个节点 | 只在这一课 |

   **当前圈默认 ≤ 8 个节点**；超出就退化为"最浅的那几个"并明说范围扩大了，不默默扩大。

## 2. 怎么长（贯穿阶段 1–3）

- **摸底回标**（阶段 1）：测出已会的整块剪掉、标 `已确认`——地图立刻告诉你"少学一半"。
- **闭环钉格**（阶段 3）：无提示复现的第一样产出就是「位置」，让他亲手把这一格钉上地图。
- **闭环后建节点笔记**：每闭环节点落一篇 `<知识点>.md`，frontmatter 写 `status` + `prereq`（wikilink 到前置）。
  **依赖边 = wikilink**，Obsidian 图谱自动画出依赖图；地图笔记只做导航层，不重复知识内容。
- **学偏了就改**：地图是假设不是合同，改一格必须便宜。

## 3. 三条不能让步的边界

1. **每条边默认只是「推测」。** 依赖图是 AI 生成的结构，属高危未核实主张；正确性**由学习过程保证**，
   不由 AI 保证——每摸底一次、每闭环一次，修正一次。
2. **规划不是教学。** 地图阶段只产结构：不引导、不展开讲解、不做完整摸底。
3. **最小充分前置（停止规则）**：不再往下挖前置的条件——ⓐ 已具备（摸底确认）；ⓑ 只有严谨性需要、
   终点能力不直接用；ⓒ 可延后。没有这条，规划必然退化成"学 X → 学 Y → … → 集合论"。

## 4. 依赖倒挂与复习（接续时做）

- **依赖倒挂检查**：接续时看图上有没有"上游没过、下游却已掌握"——有就说明记录不可信，回炉上游。
- **依赖触发的复习**：某节点被改/推翻时，它下游的"已掌握"全部回到待验证（v1 只做这一条触发，不做到期队列）。
