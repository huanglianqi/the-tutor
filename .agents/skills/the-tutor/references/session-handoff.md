# 会话交接：边界 = 记录边界

> 一个节点能在一场会话里教完，但"金融数学"不能。所以必然遇到：下次接哪里？上次说的"已掌握"能不能信？

## 1. 三条硬规则

1. **会话边界 = 记录边界**：推进到哪里，`<库>/<主题>/学习地图.md` 就写到哪里。
   **不攒到最后一次性写**——攒到最后的，会在写完前先被压缩掉。
2. **「下次入口」唯一必填**（四要素见 `state-model.md` §3）。只写「待补」的空壳不算写完。
3. **收尾或中途挂起，离开前都必须写「下次入口」——没写 = 这一场没结束。**

## 2. 接续：新会话怎么接上

**接力棒是文档，不是对话。** 旧会话上下文是过期的，开新会话、重读记录。

1. 解析学习库根（`vault-spec.md` §1），读 `学习地图.md`，**尤其「下次入口」**。
2. **读到的「已掌握」不能直接信**（`state-model.md` §2 分流）：有闭环证据→信；标 `⚠️ 未经复现验证`→
   当场最小复现；无记录→当没学过。
3. **依赖倒挂检查**：上游没过、下游却已掌握？（`learning-map.md` §4）
4. **导入别处记录，只当假设**：来源由学习者指定，每个"已掌握"当场最小复现才认。

## 3. AI 的能力边界

- AI **做不到**新建/归档会话。只能**提醒**，且：一次边界只提一次；给一段可直接复制的新会话开场白；
  明说"新建会话需要你在界面操作"；**不要谎报"已经落好了"**；不反复催。

## 4. 不可写时（只读库 / 纯对话环境）

- **小主题**：地图 + 下次入口在对话里维护，但每次开场由学习者自己复述（不要翻历史，会被压缩掉）。
- **大主题**：**做不了，要明说**——切成能单独闭环的块，一次会话只处理一块。

> 反直觉但重要：闭环做得扎实，**学习者本人就是最可靠的状态载体**。文件里写的永远是"教过"，不是"会"。
