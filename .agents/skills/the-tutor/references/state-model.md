# 状态字典（the-tutor 的唯一权威）

> **单一事实源。** the-tutor 里所有"状态字段"的取值、含义、落点，**只在本文件定义**。
> 其他文件（SKILL.md、各 reference）只能引用这里的名字，**不得重述定义**。
> 这是从两个旧技能"状态字段散落四处、同一实体两个名字"的教训里直接立下的规矩。

---

## 1. 节点状态（每个知识点节点）

| 取值 | 含义 | 谁在什么时候写 |
|---|---|---|
| `推测` | **默认值。** AI 提议，未经任何验证 | 画地图 v0 时（AI 写） |
| `未知` | 还没展开，留白 | 画地图 v0 时（AI 写） |
| `已确认` | 摸底过：学习者已经会，整块剪掉 | 阶段 1 摸底回标时 |
| `已掌握` | 走过无提示复现闭环且通过 | 阶段 3 闭环通过时，**学习者亲手钉** |

**状态迁移只沿一条路**：`推测/未知 → 已确认`（摸底剪掉）或 `推测/未知 → 已掌握`（闭环通过）。
**不允许** `已掌握 → 推测` 静默回退；发现不牢要显式降级（见 §2 掌握证据）。

## 2. 掌握证据（`已掌握` 必须有证据，防跨会话假通过）

| 取值 | 含义 | 接续时怎么处理 |
|---|---|---|
| 有闭环证据 | 走过无提示复现 且通过 | 可以信，直接往下 |
| `⚠️ 未经复现验证` | 标了"已掌握"但没走过闭环（直给、或学习者自认但未复现） | **当场做一次最小复现**再往上建 |
| 无记录 | 地图上没有这个节点 | **当作没学过** |

> 「已掌握」永远不是"点头说懂了"。文件里写的是"教过"还是"会"，由这一列区分。

## 3. 下次入口（会话边界的唯一必填区，四样缺一不可）

落在 `学习地图.md` 的 `## 下次入口` 区：

| 字段 | 要求 |
|---|---|
| 停在哪 | 哪个节点、哪一层（不是"学了一半"） |
| 卡在哪 | 他答不上来的**那一句话**（不是"有点不熟"） |
| 下一个问什么 | 下一场开场的第一问 |
| 待办 | 待补前置、`⚠️ 未经复现验证` 的节点、未核实项 |

**只写「待补」的空壳不算写完。**

## 4. 权威表述锚点（每条表述必须可溯源，或如实说没有）

| 取值 | 含义 |
|---|---|
| `强` | 指到具体出处（书 + 章节/定理号） |
| `弱` | 公开讲义 / 论文 / 可复现推导 |
| `无` | 仅 AI 表述 + 已核验，**必须显式说出来** |

> 「无锚点」是合法状态，但必须被看见——数值核验只能验"数对不对"，验不了"口径该怎么表述"。

## 5. 知识笔记的 frontmatter 字段（每闭环节点一篇）

| 字段 | 取值 | 说明 |
|---|---|---|
| `the-tutor` | `true` | 标记这是 the-tutor 写的，可被筛选/排除 |
| `status` | §1 的四个值之一 | 节点状态，Dataview 可查 |
| `prereq` | `"[[前置节点]]"`（可多个） | **依赖边 = wikilink**，Obsidian 图谱自动成图 |

> 这是 the-tutor 写的知识笔记的**全部** frontmatter 字段。刻意保持最小——每多一个字段，就多一处会漂移的副本。
> 不要照搬某个库版技能的 15 字段 frontmatter。

## 6. 学习者画像字段（库级一篇，跨主题复用）

| 字段 | 含义 |
|---|---|
| `floors` | 已会的（下限）——摸底确认过的东西 |
| `edges` | 边缘在哪（上下限之间那条前沿） |
| `misconceptions` | **系统性错误认知**——被自信持有的错误模型，必须被撬掉、不是补上 |

> 画像在摸底时更新；换主题也能复用（尤其 misconceptions）。它住在 `<库>/学习者画像.md`，
> 不是 `<主题>/` 里——因为它跨主题。

## 7. 落盘位置（谁写哪个文件）

| 文件 | 谁写 | 装什么 |
|---|---|---|
| `<库>/<主题>/学习地图.md` | 技能运行时写 | 导航层：依赖图 + 状态总览 + 下次入口 |
| `<库>/<主题>/<知识点>.md` | 技能运行时写 | 每个闭环节点一篇（§5 的 frontmatter + 内容） |
| `<库>/学习者画像.md` | 技能运行时写 | §6 的画像字段，跨主题 |

> 完整落盘/通道约定（目录、命名、MCP 通道）见 `vault-spec.md`，本文件只负责"字段"这一件事。
