# 摸底诊断：链式漏斗 + 三层 + 边缘夹逼

> 目的：确定真实起点，**不默认学习者懂任何前置**。摸底本身也是教学的一部分。

## 1. 链式漏斗（顺序）

- 为目标主题列出**知识依赖链**（如 中心极限定理 ← 正态分布 ← 方差 ← 期望 ← 随机变量）。
  若主题还是"领域"、链不存在 → 先走 SKILL.md §3（画地图），不要在对话里现编图。
- **沿链一个节点一个节点测，一个问题一个问题问**：前一个没过，不测后面；前一个问题没过，不问下一个。
- 开局**不**一次性发 3–5 道诊断题；逐题，根据回答决定下一题方向（过→前进，卡→下沉）。
- 发现前置缺口 → 开支线引导补到"足够理解主线"，再回主线。

## 2. 三层诊断模型（每个知识点都按这三层测）

| 层 | 名称 | 检验方式 | 不过的处理 |
|---|---|---|---|
| **L1 概念** | 能用自己的话讲清 | "用你的话说说 X 是什么"，看能否被追问不卡壳 | 引导构建概念 |
| **L2 形式化** | 能写公式/规范记号 + 逐符号含义 | 写出并解释每个符号、为什么这样设计 | 逐符号引导构建 |
| **L3 应用** | 能独立完成算例 | 给具体数据，独立算出 | 先带做一个范例，再独立做 |

**关键判断**：L1 过、L2 不过，不算掌握；会背公式、讲不清概念，也不算。任一层不过就在该层补。

> 非数学学科：L2「公式层」替换为学科的形式化层（法学=构成要件；历史=史料证据链；编程=接口契约）。
> LaTeX 只对数学/统计类强制。

## 3. 诊断方式

- **不直接问"你懂不懂 X"**——学习者无法准确判断自己的掌握水平。让他实际讲、写、算。
- 写出的错误公式是宝贵信号：不直接说错，**代入具体数据暴露矛盾**，再定位断裂点。

## 4. 边缘双向夹逼（"全对"不是通过）

- **边缘只有被夹逼住才算定位**：下限 = 答对的东西（至少知道这么多）；上限 = 答错/确实不知道的（理解在哪耗尽）。
  只有一侧几乎什么都告诉不了你。
- **两条反直觉纪律**：
  1. 一连串全对 = 题目太容易，不是摸底完成。**不许前进**，把难度猛然跳上去直到有东西断掉。
  2. 一个错误答案不是"开始讲授"的信号——先围绕它再探几问，刻画它是**粗心滑脱 / 狭窄孤立缺口 /
     系统性错误认知**。系统性错误认知最重要：被自信持有的错误模型必须被撬掉，不只是补上。
- **方法**：对边缘做二分查找——拿下就猛跳，失手就收窄，几次钉准。

> 摸底测的是"进来时会不会"；SKILL.md §5 的无提示复现测的是"出去时会不会"。两把尺子同构、方向相反：
> 只做摸底会产生"诊断全过、学完还是不会"的假象。
